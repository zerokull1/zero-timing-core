# Дорожная карта протокольного ядра для 10GbE-стойки (Dell PowerEdge R730 / Xeon E5-2690 v4)

## Аппаратный фундамент (35 МБ L3 кэша + Intel CAT + two_level_gate)
Благодаря двухуровневому входу (`two_level_gate`) и побитовым SWAR-маскам в L3-кэше `Xeon E5-2690 v4` (закреплённом через `Intel CAT`) добавление новых протоколов не создаёт линейных цепочек `if-else` и сохраняет нулевой промах в DDR.

## 4 целевых протокольных контура для 10G–100G
1. **HTTP/2 & HTTP/3 (`QPACK / HPACK` Bombs + `Rapid Reset`):** контроль коэффициента расширения заголовков и частоты `RST_STREAM` в скользящем окне `TSC`.
2. **TLS 1.3 `ECH` + Post-Quantum (`ML-KEM / Kyber`):** многосегментная верификация крупных `ClientHello` без ложных блокировок при сохранении отсечки микро-фрагментации (`record_len < 40`).
3. **Industrial & Robotics (`EtherCAT 0x88A4`, `PROFINET 0x8892`, `Modbus TCP`, `ROS 2 DDS`):** контроль детерминированных временных окон и запрет неавторизованных команд записи.
4. **AI-Cluster & Storage (`RoCEv2 / RDMA`, `NVMe-oF`, `gRPC`):** проверка целостности заголовков RDMA/gRPC между вычислительными узлами.
5. **Perimeter Anti-Evasion (eBPF Verifier-Safe):** блокировка `TCP Window Squeezing` (`win < 64` на этапе рукопожатия) и несоответствия геометрии потока заявленному `SNI`.
